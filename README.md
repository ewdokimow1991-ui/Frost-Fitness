# Frost Fitness

Android-приложение персонального фитнеса.

## MVP
- Kotlin + Jetpack Compose.
- Тёмный интерфейс с ярко-зелёным акцентом и логотипом FF.
- Onboarding: цель → базовые параметры → обязательный блок здоровья и ограничений.
- Медицинские данные не используются для диагностики или лечения; ограничения должны влиять на подбор упражнений и интенсивности.

## Следующие этапы
1. Профиль: опыт, оборудование, частота тренировок и возможность менять ограничения здоровья.
2. Генератор персональной программы с правилами безопасности.
3. Тренировка: упражнения, подходы, вес, повторения, таймер отдыха.
4. История и прогрессия нагрузки.
5. Питание/БЖУ и замеры.
6. Локальное хранение данных для MVP.
